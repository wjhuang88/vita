# New Feature

1. Route through requirement intake and select/create a ready Story.
2. Read linked ADR/reference and list success criteria before coding.
3. Identify affected risk surfaces: boot, disk, privilege, secret, network, external model/provider.
4. Add focused tests before broad refactoring.
5. Prove the feature is reachable from the runnable product path.
6. Update reference/user documentation for observable behavior.
7. Record evidence and synchronize story/iteration status.
