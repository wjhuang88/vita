# Evolution Feedback

Write a lesson to `EVOLUTION.md` when a corrected omission, repeated failure, newly discovered project trap or unexpectedly successful workaround is likely to matter again.

Entry shape:
- Trigger
- Symptom
- Cause
- Remedy
- Prevention
- Promotion target

If a lesson becomes mandatory, promote it into `AGENTS.md`, a SOP, a test/harness check or an ADR. Do not rely on lesson history as the only source of current rules.
