# Documentation Check

Before closing a change:
- `AGENTS.md` routes recurring process correctly.
- Stable facts are in `docs/reference/`; procedures in `docs/sop/`; decisions in `docs/decisions/`; work/status in backlog/iterations.
- Backlog and iteration states do not contradict each other.
- Board is derived from owners and is updated last.
- Relative Markdown links resolve.
- Observable behavior changes are reflected in root README/reference/user guidance.
- Assumptions are labeled rather than written as confirmed architecture.
