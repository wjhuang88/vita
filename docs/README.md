# Documentation Map

| Area | Owner | Purpose |
| --- | --- | --- |
| Current operating view | `BOARD.md` | Derived Now/Next/Blocked view; never the source of truth |
| Product backlog | `backlog/PRODUCT-BACKLOG.md` | Prioritized outcomes and required reads |
| Active executable work | `backlog/active/` | Epic, Story and Spike detail |
| Iterations | `iterations/` | Published execution baselines and evidence |
| Architecture decisions | `decisions/` | Tradeoffs, constraints and reversal triggers |
| Roadmap | `roadmap/IMPLEMENTATION-ROADMAP.md` | Stage ordering and sequencing rationale |
| Proposals | `proposals/` | Immature directions, not executable work |
| Stable project facts | `reference/` | Architecture, contracts, layout and threat model |
| Human acceptance | `validation/` | Explicit manual tests, deferred requirements and evidence handoffs |
| Procedures | `sop/` | Repeatable process and validation gates |

Start with `../AGENTS.md` for routing.
